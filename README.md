# homebrew-minikube-support
Homebrew Tap for the [minikube-support](https://github.com/qaware/minikube-support) Tools
```shell script
brew install --cask qaware/minikube-support/minikube-support
```

Existing formula installations are migrated to the cask on `brew update`.
If Homebrew reports the migration target as not trusted, finish the
migration with:
```shell script
brew trust --cask qaware/minikube-support/minikube-support
brew install --cask qaware/minikube-support/minikube-support
```
